Sobre mí

Soy Humberto Fuentes Martínez, radioaficionado activo desde La Serena, Región de Coquimbo, Chile (locator FG40). La radio no es solo un hobby — es un puente entre el pasado analógico y el futuro digital de las comunicaciones.

Desde mis primeros contactos en HF hasta los concursos internacionales, cada QSO es una historia. Me apasiona la construcción de antenas experimentales, el estudio de la propagación ionosférica y compartir este arte con la comunidad.

Con más de 16.000 búsquedas en QRZ.com y 11 diplomas internacionales obtenidos entre 2023 y 2026, mantengo una presencia activa en bandas de 10 y 40 metros en modos SSB, FT8 y mixto.

Programación de Radio Kirisun FM540: Fabricación de Cable y Resolución de Problemas Paso a Paso

Todo comenzó con un desafío práctico: tenía en mis manos una radio móvil Kirisun FM540 que necesitaba ser programada con nuevas frecuencias, pero no contaba con el cable de comunicaciones ni con el software correcto. En vez de rendirme o comprar un cable a precio elevado, decidí ir al origen: analizar el esquemático del equipo para fabricar el cable desde cero.

// FASE 1 — ANÁLISIS DEL CIRCUITO

El primer paso fue estudiar el manual de servicio del FM540. En la página 97 (Figure 7 – KEY Board Schematic), encontré el conector J1 (J1S_FT8100): un RJ45 de 8 pines que sirve tanto para el micrófono como para la programación. El análisis reveló el pinout exacto:

Pin 1 → MD   (Microphone Data / TXD hacia radio)
Pin 6 → GND (Tierra / masa)
Pin 8 → RXD (Datos desde el radio)
⚠ Señal TTL 3.3V — no conectar directo a RS-232
// FASE 2 — FABRICACIÓN DEL CABLE

Con el pinout claro, corté un cable CAT5e de fábrica y usé un adaptador USB-Serial CP2102. Los 3 hilos necesarios (solo 3 de los 8 pines se usan para programación) se conectaron así:

RJ45 Pin 1 (naranja/blanco) → RX del CP2102 (blanco)
RJ45 Pin 6 (verde)         → GND del CP2102 (negro)
RJ45 Pin 8 (café)          → TX del CP2102 (verde)
VCC rojo → NO CONECTAR ⛔
// FASE 3 — PROBLEMÁTICA Y DIAGNÓSTICO

Al intentar leer la radio con el CPS FM540 V2.11, apareció el primer obstáculo: "port is occupied or not connected". El proceso de diagnóstico incluyó:

PROBLEMA
CPS no encontraba el puerto COM, aunque el driver CP2102 aparecía en el Administrador de Dispositivos
SOLUCIÓN
Ejecutar el CPS como Administrador de Windows y verificar que el número de COM en el software coincida con el del sistema
PROBLEMA
El software CPS V2.11 era incompatible con el firmware de la radio: error "Version is error, please select V1.XX"
SOLUCIÓN
Contactar a Kirisun directamente (service@kirisun.com) solicitando el CPS V1.29 compatible con MCU Version V01.00. Respondieron en menos de una semana
PROBLEMA
El adaptador CP2102 casero presentaba soldaduras frías — el eco de prueba en PuTTY (COM3, 9600 bps) no respondía
SOLUCIÓN
Reemplazar por cable Wakesnow "8 en 1" de fábrica. Conector correcto: M2. Driver CH341SER oficial desde wch.cn
// FASE 4 — CONFIGURACIÓN FINAL EXITOSA

Con el cable Wakesnow (conector M2), el driver CH340 correcto y el CPS V1.29, la radio fue leída exitosamente en un segundo PC con Windows 11. El proceso final fue:

1.
Instalar driver CH341SER v3.4 desde wch.cn
2.
Conectar cable Wakesnow M2 → COM3
3.
Abrir CPS FM540 V1.29 como Administrador
4.
Setting → Communication Port → COM3
5.
Encender radio → Program → Read → ✅ Lectura exitosa
6.
Editar canales y frecuencias → Program → Write → ✅ Grabación exitosa
// CONCLUSIONES Y LECCIONES APRENDIDAS

Este proyecto demostró que con paciencia y método sistemático es posible resolver cualquier obstáculo técnico. Las claves del éxito fueron: (1) leer el esquemático de servicio para entender el hardware real, (2) verificar cada eslabón de la cadena con herramientas de diagnóstico como PuTTY, (3) contactar directamente al fabricante cuando el software oficial no estaba disponible públicamente, y (4) nunca descartar el hardware físico antes de probarlo con un test de eco.

Equipo utilizado: Kirisun FM540 VHF · Cable Wakesnow 8-en-1 (M2) · CPS V1.29 · Driver CH341SER · Windows 11

Cómo modificar y publicar tu sitio

Esta guía es solo para ti, Humberto. Puedes eliminar esta sección cuando publiques el sitio si no quieres que sea visible — busca el comentario <!-- GUÍA DE MODIFICACIONES --> y borra todo hasta <!-- FIN GUÍA -->.

① ABRIR Y EDITAR EL ARCHIVO

El sitio es un solo archivo CA2HFW.html. Para editarlo:
1. Clic derecho sobre el archivo → "Abrir con" → Bloc de notas (o Notepad++, que es mejor)
2. Usa Ctrl+F para buscar el texto que quieres cambiar
3. Edita → guarda con Ctrl+S
4. Abre el archivo en Chrome/Edge para ver el resultado antes de publicar

② AGREGAR FOTOS NUEVAS

Opción A — Desde Google Drive (recomendado):
1. Sube la foto a tu Drive → clic derecho → "Obtener enlace" → Acceso: "Cualquier persona con el enlace"
2. Copia el ID de la URL: en drive.google.com/file/d/1ABC...xyz/view el ID es la parte subrayada
3. En el HTML reemplaza el ID en: thumbnail?id=AQUÍ_TU_ID&sz=w600

Opción B — Para agregar una foto nueva en la galería:
Busca en el HTML: <!-- FOTO 10 --> y copia ese bloque debajo. Cambia el ID de la imagen y el texto del overlay.

③ AGREGAR UN DIPLOMA NUEVO

1. Sube el PDF del diploma a Google Drive → clic derecho → "Obtener enlace"
2. Busca en el HTML: <!-- POTA New Year --> y copia ese bloque diploma-card
3. Cambia el emoji, el título, la descripción y el ID del PDF en el onclick:

onclick="window.open('https://drive.google.com/file/d/ID_DEL_PDF/view','_blank')"
④ AGREGAR UNA QSL NUEVA

1. Sube la imagen de la QSL a Google Drive y hazla pública
2. Busca en el HTML: <!-- KK7ZZM — USA -->
3. Copia ese bloque qsl-card y pégalo al final de la grilla
4. Reemplaza: el ID de la imagen en thumbnail?id=ID, la bandera 🏳️, el país y los datos del QSO en el overlay

⑤ PUBLICAR EL SITIO EN INTERNET (GRATIS)

Con Netlify Drop — la forma más fácil, sin registro:

1. Ve a netlify.com/drop
2. Arrastra el archivo CA2HFW.html al recuadro
3. ¡Listo! Netlify te da una URL pública en segundos
4. Ejemplo: ca2hfw.netlify.app (puedes personalizar el nombre)

Para actualizar el sitio después: vuelve a netlify.com/drop y arrastra el archivo modificado. La URL no cambia.
